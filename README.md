# R, SQL and data management course

An interactive course on All of Us EHR data, SQL, R data management, target trial emulation and reading survival-analysis output.

- `public/index.html`: the course (one page).
- `public/sql-asm.js`: the SQL engine (sql.js 1.11.0, MIT licence) that runs the exercises in the browser.

Hosted on Cloudflare Pages. Build command: `exit 0`. Build output directory: `public`.

All numbers in the course are made up or come from simulated data. No All of Us participant data is included.
